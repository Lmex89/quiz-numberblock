# AGENTS.md

## Project overview

Educational quiz web app (Spanish) for children: count objects or sum their values. FastAPI backend serves a vanilla JS frontend. No build step, no test framework, no CI.

## Run the app (two terminals)

**Terminal 1 — Backend API (port 8000):**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

**Terminal 2 — Frontend (port 9093):**
```bash
python3 -m http.server 9093 --bind 0.0.0.0 --directory frontend
```

Open `http://localhost:9093` or `http://<TU_IP_LOCAL>:9093`.

## Structure

| Path | Role |
|---|---|
| `backend/main.py` | FastAPI entrypoint — JSON API |
| `backend/game_logic.py` | Quiz generation ("count" and "sum" game types) |
| `backend/session_manager.py` | In-memory session store (per-browser streak) |
| `frontend/` | Vanilla HTML + CSS + JS (no framework, no bundler) |
| `static/images/` | `1.jpg`–`20.jpg` placeholder images, generated by `static/images/generate_placeholders.py` |

## Key details

- **Session tracking**: Via `X-Session-Id` header. The backend returns a `session_id` in every quiz response; the frontend stores it and sends it back in subsequent requests. Streaks reset on wrong answers. State is in-memory (lost on server restart).
- **Ports**: Backend on `:8000`, frontend served on `:9093`. CORS configured to allow any origin (local network). Both servers bind `0.0.0.0` for LAN access.
- **Image generation**: Run `python static/images/generate_placeholders.py` (requires Pillow). Needed only if images are missing.
- **No tests, no lint, no typecheck** — none configured.
- **Logging**: Uses `loguru` throughout backend. Levels: `info` for key events (quiz generated, answer verified, session created), `debug` for image picks/distractors, `warning` for mismatches, `error` for missing sessions. Configured by loguru defaults (stderr, `DEBUG`+).
- **Spanish UI**: All visible strings are in Spanish (`index.html`, `count.js`, `sum.js`). Keep game_type strings in English (`"count"`, `"sum"`).
- API serves JSON; frontend `js/api.js` uses `fetch` with no abstraction.
- `count.html` and `sum.html` load their game type as `<script src="/js/count.js">` and `<script src="/js/sum.js">`.
- **Images**: Replace placeholders in `static/images/` with real images (same filenames 1.jpg–20.jpg). The filename number is the image's value for the sum game. Regenerate placeholders anytime with `python static/images/generate_placeholders.py`.
- **WebP fix**: If your real images are WebP or PNG, run `python static/images/convert_webp_to_jpg.py` to convert them all to proper JPEG (200×200).
